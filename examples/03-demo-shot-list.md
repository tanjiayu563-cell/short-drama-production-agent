# 示例输出｜风格锁定与逐镜分镜

> 假设用户已选择“方案 A｜冷湿悬疑”。  
> 本示例用于展示交付颗粒度，不对应真实平台当前技术规格。

## 1. 制作摘要

- 项目：《门外的第二份外卖》
- 画幅：竖屏 9:16
- 建议时长：约 50–60 秒
- 制作方式：低预算实拍
- 主要场景：合租公寓客厅、公寓公共走廊
- 主要人物：林夏、陈默
- 风格：冷湿悬疑、低饱和、硬切、声音驱动

## 2. Style Lock

| 项目 | 设计 |
|---|---|
| 视觉命题 | 日常出租屋被一条不该存在的订单侵入 |
| 主色 | 雨夜蓝灰 `#4B5C66` |
| 辅色 | 走廊荧光绿 `#86A38B`、室内旧台灯暖黄 `#C08A4A` |
| 饱和度 | 低；肤色保留自然暖度 |
| 对比度 | 中高；暗部保留可辨细节 |
| 灯光 | 室内台灯为主光，手机冷光补脸；走廊使用顶部荧光灯和湿地面反光 |
| 镜头 | 35mm、50mm 为主；固定机位为主，两次缓慢推近 |
| 构图 | 门框、门缝、手机和塑料袋形成压迫性边框 |
| 剪辑 | 硬切；信息点后留半拍，不做花哨转场 |
| 声音 | 雨声贯穿；电梯声、消息提示、门链、敲门声承担叙事 |
| 表演 | 克制；以停顿、呼吸和视线反应为主 |
| 禁止项 | 无血腥、无跳吓、无夸张鬼影、无品牌真实 Logo |

## 3. 人物与场景一致性

### 林夏

- 28 岁，独居；低马尾，灰色宽松针织衫、黑色家居裤；
- 右手拿黑色手机，手机壳有一道白色磨痕；
- 行为习惯：先用手机边缘抵住掌心，再靠近门；
- 不可变化：低马尾、灰色针织衫、右手机；
- 情绪变化：确认暗号前的警觉 → 看到门外人的迟疑 → 听到第二次敲门时的僵住。

### 陈默

- 25 岁，外卖员；黑色短发湿透，深色雨衣外穿黄色外卖马甲；
- 左手提蓝色保温袋，右手拿订单小票；
- 鞋底和袋底持续滴水；
- 不可变化：黄色马甲、左手提袋、右手小票、湿发；
- 表演基线：疲惫、回避冲突，不主动解释过多。

### 场景

- 室内：门在画面左侧，客厅窗户在右侧；台灯在沙发边；餐桌位于画面下方；
- 走廊：门外灯光偏绿，电梯在门左后方，地面有反光水迹；
- 轴线：室内镜头中林夏位于画面右侧，面向左侧的门；陈默进门后位于画面左侧，面向右侧；
- 关键道具：外卖小票和手机订单号统一为 `7319`。

## 5. 关键镜头卡：S01-10

- **叙事功能**：第二次敲门推翻“外卖已送到”的单一解释，把普通入室变成不可控事件。
- **情绪变化**：短暂安全 → 警觉 → 僵住。
- **景别 / 机位**：门板和门把手特写，平视，略低于人物视线。
- **镜头**：50mm，固定；门把手位于画面下方三分之一，门链在画面上方留白。
- **动作**：门把手先轻微下压，静止一拍，再三下敲门；门链随之轻晃。
- **表演**：镜头内不出现完整人脸，仅让林夏的手从画面右侧短暂入画又停住。
- **灯光**：走廊荧光从门缝漏入，室内暖灯只照亮门框边缘。
- **声音**：三下敲门不必等距；第一下重、第二下轻、第三下带回声；手机提示音在第二下后插入，制造信息冲突。
- **转场**：硬切到 S01-11 手机屏幕。
- **连续性**：陈默已在室内；门链为空；订单已送达提示必须同时与屋内外卖员矛盾。
- **制作难度**：低；难点是门板震动和声音节奏。
- **备选方案**：若门把手不适合特写，改拍门缝下光影变化和地面水迹，声音保持不变。
