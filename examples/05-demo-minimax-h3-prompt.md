# 示例输出｜MiniMax H3 小说选区分镜提示词

> 示例项目：《门外的第二份外卖》  
> 选区：林夏发现订单号、让陈默进门、保温袋滴水  
> 模型：MiniMax-H3  
> 输出：6 秒，9:16，2K，24 fps  
> 说明：参考图名称是占位示例，实际生成时需要导入对应人物与场景图片。

## 1. 选区

```text
林夏低头看手机。订单号也是 7319。
她解开门链，把陈默放了进来。男人进门后没有脱鞋，蓝色保温袋在地垫上积出一小滩水。
```

## 2. 一致性资产

- C01 林夏：低马尾、灰色宽松针织衫、右手黑色手机、手机壳白色磨痕。
- C02 陈默：黑色湿发、深色雨衣、黄色外卖马甲、左手蓝色保温袋、右手小票。
- S01 公寓客厅门区：门在画面左侧，旧台灯在右后方，门链固定在门框上。
- P01 黑色手机：右手持，屏幕内容后期合成。
- P03 蓝色保温袋：陈默左手持有，袋底持续滴水。

## 3. MiniMax H3 单镜提示词

```text
MiniMax H3 参考生成。6 秒，9:16，2K，24 fps，使用原生立体声。项目《门外的第二份外卖》，镜号 S01-07。

Image 1（reference_image；角色 C01 林夏）：只参考林夏的脸、低马尾、自然肤色和灰色宽松针织衫；不参考原图背景。必须保持：灰色针织衫、低马尾、右手黑色手机、手机壳白色磨痕；不要换装。
Image 2（reference_image；角色 C02 陈默）：只参考陈默的黑色湿发、深色雨衣、黄色外卖马甲和体型；不参考原图背景。必须保持：黄色马甲外穿、深色雨衣、左手蓝色保温袋、右手纸质小票；不要换装。
Image 3（reference_image；场景 S01 公寓客厅门区）：只参考门在画面左侧、门链位置、旧台灯和空间布局；不参考任何人物。必须保持：门在左侧、旧台灯在右后方、门口地垫位置固定。
Image 4（reference_image；道具 P03 蓝色保温袋）：只参考保温袋的蓝色、尺寸和提手；袋底必须持续滴水。

剧情与动作：
林夏站在门内右侧，面向左侧的门；陈默站在门外左侧，面向林夏。起始画面中，林夏右手握着黑色手机，手机屏幕亮起，订单号 7319 与纸质小票上的号码一致。林夏先看小票，再抬眼确认陈默；她解开门链，把门拉开，陈默侧身进入室内，左手蓝色保温袋落在地垫边缘，袋底滴下一小滩水。

0–2 秒：林夏低头看手机，右手拇指停在订单号旁；镜头固定，焦点落在手机和她的手指上。手机屏幕文字保持模糊，号码细节后期合成。
2–4 秒：林夏抬眼看向门外；陈默仍站在画面左侧，右手举着小票。门链保持挂上，镜头不横移。
4–6 秒：林夏解开门链，门被拉开；陈默侧身进入，蓝色保温袋轻轻碰到地垫，水滴落下。镜头固定，人物不要走出画面。

镜头：中景，平视，50mm 等效焦段，固定机位，不推拉、不绕拍。竖屏构图把门框放在画面左侧，林夏在右侧，陈默在左侧，地垫在下方前景。
光影与色彩：室内旧台灯从右后方提供暖光；手机冷光补亮林夏脸部；走廊绿色荧光从门缝进入画面左侧；低饱和蓝灰主色，中高对比但保留暗部细节。
声音：雨声、门链金属声、拖鞋摩擦、塑料袋轻响和水滴滴落地垫；无音乐。对白不多于一句，由后期配音或单独音频生成。
连续性：林夏始终在门内右侧；陈默从门外左侧进入室内左侧；右手机、右手小票、左手蓝色保温袋；门打开方向一致；地垫和暖光位置不变。
禁止项：不新增人物；不换真实外卖平台 Logo；不生成可读字幕；不要血腥、鬼影或夸张表情；不要改变人物左右位置、门的开合方向、门链位置和服装。
```

## 4. 验收标准

- 林夏、陈默的身份、发型、服装和小票/保温袋持握侧保持一致；
- 手机界面不要由生成模型承担，后期合成 `7319`；
- 门把手、门链和开门方向连续；
- 陈默进入室内时，人物和保温袋不穿门、不穿人；
- 滴水位置可接下一镜；
- 画面没有新增人物、真实平台 Logo 或错误文字；
- 第一帧可接 S01-06，末帧可接 S01-08。

## 5. 失败后的首选处理

| 问题 | 处理 |
|---|---|
| 手机文字变形 | 生成空屏幕，后期合成订单界面 |
| 陈默进门时手部穿模 | 拆成“门链特写”“袋底滴水”“陈默侧身进门”三镜 |
| 保温袋换手或消失 | 增加 P03 参考图，写死左手持袋和袋底滴水 |
| 门链消失 | 单独拍门链特写，或把开门动作改成画外声 + 林夏反应 |
| 人物身份漂移 | 减少同镜人物数量，分别生成林夏和陈默单人中景，再用剪辑接戏 |
