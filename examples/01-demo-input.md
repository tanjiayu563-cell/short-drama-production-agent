# 示例输入｜原创悬疑短剧《门外的第二份外卖》

## 用户输入

```text
使用 $short-drama-production。

平台/画幅：竖屏 9:16
单集时长：约 60–90 秒
制作方式：低预算实拍
目标受众：喜欢都市悬疑和反转的年轻观众
必须保留：外卖暗号、同一订单号、门外第二次敲门
不能出现：血腥画面、儿童演员、车辆追逐
预算或周期：低预算，主要使用一套合租公寓和公共走廊

标题：《门外的第二份外卖》
一句话创意：暴雨夜，独居的林夏收到一份带有失踪姐姐暗号的外卖；
她刚把外卖员放进屋里，门外却又响起同一订单号的敲门声。

主要人物：
林夏，28 岁，独居，谨慎，三年前姐姐林秋失踪。
陈默，25 岁，外卖员，疲惫，不想卷入麻烦。

请先诊断剧本，再给我视觉风格方案。我选择方案后再做最终分镜。
```

## 为什么这是好的测试输入

- 有明确冲突、信息差和集尾钩子；
- 场景少，适合低成本实拍；
- 关键信息可以通过手机、声音和人物反应呈现；
- 同时存在多个视觉上可行但成本不同的风格方向；
- 可以检查风格闸门、轴线、手机文字、门外空间和声音连续性。
