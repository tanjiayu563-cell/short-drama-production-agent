# 示例中间交付｜视觉风格方案

> 本示例假设尚未确认风格，因此不直接输出最终分镜。

## 共同前提

- 画幅：竖屏 9:16；
- 时长：约 60–90 秒；
- 制作方式：低预算实拍；
- 主场景：合租公寓客厅与公共走廊；
- 视觉核心：日常空间被一个不合常理的订单打破。

## 方案 A｜冷湿悬疑（推荐）

**一句话视觉命题**：让雨水、手机冷光和走廊荧光把熟悉的出租屋变成不可信的空间。

- **色彩与影调**：蓝灰色为主，低饱和；走廊偏绿色荧光，室内保留少量暖色台灯；中高对比，暗部保留细节。
- **镜头语言**：35mm 与 50mm；多数固定机位，关键信息点用缓慢推近；避免炫技运镜。
- **人物与服化道**：林夏穿灰色家居服，头发略乱；陈默雨衣和外卖服明显湿透，鞋底带水。
- **场景与美术**：门口地垫、漏水痕迹、手机屏幕、塑料袋水珠作为反复视觉元素。
- **剪辑与声音**：硬切为主；突出雨声、电梯声、消息提示音和敲门声；音乐尽量少用。
- **代表镜头**：手机备注特写；猫眼鱼眼里的外卖员；门外第二次敲门时门把手的轻微转动。
- **制作优势**：单一场景可完成，光线可控，悬疑感明确。
- **成本与风险**：需要控制手机屏幕反光和门外走廊声音，确保湿衣连续。
- **最不适合**：偏浪漫、温暖或轻喜剧的版本。

## 方案 B｜暖色旧忆悬疑

**一句话视觉命题**：姐姐留下的暗号像一段不肯结束的家庭记忆，危险藏在温暖表象下。

- **色彩与影调**：琥珀色、旧木色和低饱和绿；高光柔和，胶片颗粒明显。
- **镜头语言**：50mm 浅景深，短距离手持，更多停留在人物脸部和旧物上。
- **人物与服化道**：林夏的家居服更旧，家里有姐姐留下的杯子、照片和便签。
- **剪辑与声音**：慢节奏，雨声压低，加入冰箱嗡鸣和远处电视声。
- **代表镜头**：旧照片边缘与外卖单重叠；林夏在暖灯下读出姐姐的暗号。
- **制作优势**：情感层次更强，人物关系更清楚。
- **成本与风险**：需要更细致的美术陈设；容易削弱开场的紧迫感。
- **最不适合**：要求快速强钩子的版本。

## 方案 C｜高反差荒诞惊悚

**一句话视觉命题**：公寓像一只被外卖系统操控的盒子，人物的日常动作逐渐失真。

- **色彩与影调**：高对比，冷绿和品红点缀，手机屏幕成为主要光源。
- **镜头语言**：24mm 广角、俯拍和轻微荷兰角；声音空间不自然。
- **人物与服化道**：造型更类型化，外卖员像系统的一部分。
- **剪辑与声音**：突然静音、抽帧、低频和重复提示音。
- **代表镜头**：从走廊顶灯俯拍人物；猫眼画面拉伸；门缝里出现第二袋外卖。
- **制作优势**：视觉记忆点强，适合短平台。
- **成本与风险**：对灯光、美术和后期要求更高，低预算下容易显得刻意。
- **最不适合**：低预算、单一自然光拍摄。

## 推荐与询问

**推荐：方案 A。**

理由：它最贴合现有场景和低成本实拍，能用声音、手机屏幕和人物反应制造悬念，不需要复杂特效。

代价：视觉上较克制，需要靠演员反应和声音节奏维持张力。

请选择 A、B 或 C，或说明要混合的具体部分。确认前不生成最终逐镜分镜。
