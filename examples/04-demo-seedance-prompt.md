# 示例输出｜Seedance 视频生成提示词包

> 示例项目：《门外的第二份外卖》  
> 目标镜头：S01-10  
> 风格：方案 A｜冷湿悬疑  
> 说明：平台 UI/API 参数可能不同；以下内容用于展示提示词组织方式，不构成 Seedance API 文档。

## 1. Model Profile

| 项目 | 信息 |
|---|---|
| 模型 | Seedance 2.5（按官方公开能力配置） |
| 官方页面 | <https://seed.bytedance.com/zh/seedance2_5> |
| 最后核验 | 2026-11-02 |
| 生成任务 | I2V / R2V（以实际产品入口为准） |
| 输入模态 | 文字、图片、视频、音频等多模态参考 |
| 原生音频 | 官方宣传支持音视频联合生成；具体入口需核验 |
| 单次生成时长 | 官方称 30 秒；本项目目标镜头仍按约 4 秒设计 |
| 视频延长 | 官方称支持两次视频延长 |
| 时间戳编辑 | 官方称支持 |
| 参考能力 | 官方称最多 30 张图片、10 段视频、10 段音频 |
| 已知限制 | 官方指出复杂运动物理和极多主体交互仍有提升空间 |

## 2. 参考资产

```text
@图片1：林夏角色外观锚点。只参考低马尾、脸型、自然肤色、灰色宽松针织衫和右手黑色手机；不参考原图背景。
@图片2：客厅门区场景锚点。只参考门在画面左侧、门链位置、旧台灯与门框比例；不参考人物。
@图片3：陈默角色外观锚点（如镜头需要其手部入画）。只参考黄色外卖马甲、深色雨衣和湿发状态。
```

## 3. 镜头任务

- 叙事功能：第二次敲门推翻“订单已送达”的单一解释。
- 起始状态：陈默已在屋内，门关闭，门链为空；林夏右手握手机，停在画面右侧。
- 关键动作：门把手先轻微下压，静止一拍，再三下敲门；门链轻晃；手机提示“订单 7319 已送达”。
- 结束状态：门把手停止，门板余震；林夏的手停在半空。
- 时长：约 4 秒。
- 画幅：竖屏 9:16。
- 核心声音：三下不均匀敲门声和手机提示音。

## 4. 完整提示词

```text
任务：生成一个约 4 秒的竖屏悬疑镜头，参考 @图片1、@图片2 和 @图片3 保持角色与空间一致。

画面主体是公寓客厅的门板与门把手，门位于画面左侧。镜头为近景特写，平视，机位略低于人物视线，50mm 等效焦段，固定机位，无推拉摇移。门把手位于画面下方三分之一，门链在画面上方形成留白。林夏穿灰色宽松针织衫，右手握黑色手机，只让她的右手和少量袖口从画面右侧入画，不出现完整面部。

0–1 秒：门把手先轻微向下压，随后停住。室内旧台灯从画面右侧提供暖光，走廊绿色荧光只从门缝和把手下方漏入。环境只有压低后的雨声。
1–2 秒：门把手静止，林夏握着手机的右手从画面右侧缓慢进入，停在半空。手机冷光在她手背上形成一小块反光。
2–4 秒：门板连续响三下：第一下重，第二下轻，第三下带回声；门链随敲门轻微晃动。第二下之后，手机屏幕亮起“订单 7319 已送达”，冷光短暂扫过门框。

保持低马尾角色的手部比例、灰色针织衫袖口、黑色手机、门链位置、旧台灯右后方暖光和走廊左侧绿色荧光。保持门在画面左侧，摄影机固定。不要新增完整人物，不要改变服装，不要出现真实平台 Logo，不要生成可读字幕，不要加入鬼影或血腥画面。
```

如果产品支持独立负面提示词，可将最后一句拆成：

```text
negative_prompt: 完整人物，换装，真实外卖平台 Logo，可读字幕，鬼影，血腥，镜头横移，快速推拉，门的位置改变，门链消失，多余手指，手部变形
```

## 5. 生成参数建议

这些是提示词包中的设计建议，不是 Seedance API 固定参数名：

```text
模型：Seedance 2.5（以实际入口为准）
目标时长：约 4 秒
画幅：9:16
模式：参考图片生成 / 多模态参考生成
摄影机：固定
音频：需要敲门声、手机提示音和压低雨声
参考强度：角色和场景需要较高；动作参考不适用
随机种子：首次生成后记录；用于同风格复现测试
```

## 6. 验收标准

- 门把手先下压，再出现三下敲门，顺序不能颠倒；
- 林夏只出现右手和袖口，不能突然出现完整人物；
- 灰色针织衫、黑色手机、低马尾角色手部比例一致；
- 门链必须在画面中可见并轻晃，不能消失；
- 手机提示可以在后期合成，但画面要给屏幕留出位置；
- 暖光来自右后方，走廊绿光来自门缝，不能全场换色；
- 画面无真实平台 Logo、可读字幕、鬼影和血腥元素；
- 首帧可接 S01-09 的室内双人镜，末帧可切到 S01-11 的手机特写。

## 7. 高风险与替代方案

| 风险 | 处理 |
|---|---|
| 手机屏幕文字变形 | 生成空屏幕，后期合成“订单 7319 已送达” |
| 手部进入画面时变形 | 拆成门把手特写和手部插入镜两个生成任务 |
| 敲门动作与声音不同步 | 画面只生成门板震动，声音在后期按剪辑点设计 |
| 门链晃动不稳定 | 使用局部特写或后期合成门链动画 |
| 模型新增完整人物 | 减少提示中的角色信息，只保留“手和袖口入画” |
