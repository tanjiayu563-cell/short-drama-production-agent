# MiniMax H3 小说选区分镜工作台

这是一个本地单文件 HTML 工具，不上传文本或图片到第三方。

## 使用

1. 双击 `index.html`，或在浏览器中打开；
2. 粘贴小说文本，或导入 `.txt` / `.md` / `.epub`；
3. 在文本框中用鼠标选中要改编的区域；
4. 在“一致性资产”中导入人物/场景图片，或填写文字描述与一致性锁；也可以通过“导入资产卡 JSON”或“粘贴 JSON”载入资产卡；
5. 确认本次镜头使用的人物、场景和道具；
6. 点击“自动拆解选区”，检查每个节拍是画面、对白、旁白、画外声还是文字插入；
7. 从拆解结果中选择一个节拍“应用到单镜”，再填写景别、运镜、光影、声音；
8. 点击“生成 H3 提示词”；
9. 复制提示词到 MiniMax H3，或导出 Markdown/项目 JSON。

## 当前支持

- `.txt` / `.md` / `.epub` 导入；EPUB 在浏览器本地解压并按 spine 顺序提取正文；
- 小说区域的鼠标选区捕获；
- 人物、场景/背景、道具三类资产；
- 参考图导入与本地压缩；
- 无图片时使用文字描述和一致性锁；
- 选区名称/别名自动匹配；
- 自动拆解画面、对白、旁白、画外声和文字插入镜；
- 人物关系与关系调度提示；
- 镜头景别/机位去重复检查；
- MiniMax H3 提示词生成；
- 7000 字符上限和参考图数量提醒；
- 项目 JSON、提示词 Markdown 导出；
- 资产卡 JSON 导入，只替换资产，不清空小说正文；
- 文件选择器不可用时，可直接粘贴 JSON 导入；
- 最近 10 个版本记录。

## 自动调用 MiniMax H3

1. 在终端设置 `MINIMAX_API_KEY`；
2. 运行：
   ```bash
   python3 skills/short-drama-production/scripts/local_server.py --port 8787
   ```
   如果从仓库运行，路径改为 `skill/scripts/local_server.py`；
3. 打开 `http://127.0.0.1:8787/workbench/index.html`；
4. 生成并确认当前镜头；
5. 点击“确认并生成 H3”。

默认使用 4 秒、768P、9:16、单镜生成，适合低成本首测。API Key 不会进入浏览器。

## 注意

- 大体积 EPUB 可能超过浏览器自动保存容量；如果导入后提示自动保存失败，当前页面仍可继续使用，重新打开时需要重新导入。
- 建议每次选段生成后立即复制或导出 Markdown。

## 当前不支持

- 直接解析复杂 `.docx` 排版、表格和批注；
- 自动调用 MiniMax API 生成视频；
- 处理带 DRM 的 EPUB；
- 自动判断图片是否真的是同一个角色；
- 保证模型一定保持人物和背景一致。

提示词层能锁定人物/场景 ID、参考图顺序、服装、道具和空间；最终一致性仍要通过实际生成视频质检确认。
