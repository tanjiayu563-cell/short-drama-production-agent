# MiniMax H3 小说选区分镜工作台

这是一个本地单文件 HTML 工具，不上传文本或图片到第三方。

## 使用

1. 双击 `index.html`，或在浏览器中打开；
2. 粘贴小说文本，或导入 `.txt` / `.md` / `.epub`；
3. 在文本框中用鼠标选中要改编的区域；
4. 在“一致性资产”中导入人物/场景图片，或填写文字描述与一致性锁；
5. 确认本次镜头使用的人物、场景和道具；
6. 填写镜头目的、景别、运镜、光影、声音等；
7. 点击“生成 H3 提示词”；
8. 复制提示词到 MiniMax H3，或导出 Markdown/项目 JSON。

## 当前支持

- `.txt` / `.md` / `.epub` 导入；EPUB 在浏览器本地解压并按 spine 顺序提取正文；
- 小说区域的鼠标选区捕获；
- 人物、场景/背景、道具三类资产；
- 参考图导入与本地压缩；
- 无图片时使用文字描述和一致性锁；
- 选区名称/别名自动匹配；
- MiniMax H3 提示词生成；
- 7000 字符上限和参考图数量提醒；
- 项目 JSON、提示词 Markdown 导出；
- 最近 10 个版本记录。

## 当前不支持

- 直接解析复杂 `.docx` 排版、表格和批注；
- 自动调用 MiniMax API 生成视频；
- 处理带 DRM 的 EPUB；
- 自动判断图片是否真的是同一个角色；
- 保证模型一定保持人物和背景一致。

提示词层能锁定人物/场景 ID、参考图顺序、服装、道具和空间；最终一致性仍要通过实际生成视频质检确认。
