# 质量闸门与成功/失败判定

## 1. 硬性通过项

任一项不通过，即不得标为“可执行交付”。

1. **输入忠实**：核心人物关系、关键因果、用户指定台词和结局没有被静默改写；改动均有记录。
2. **叙事完整**：每场有目标、阻力、信息或情绪变化；关键转折能被观众理解。
3. **风格已锁定**：风格闸门已关闭；视觉方案不是形容词堆积。
4. **镜头可执行**：每镜有景别、角度/机位、镜头或运动、动作、声音、时长建议与连续性。
5. **空间连续**：轴线、视线、银幕方向、人物位置和动线成立。
6. **物料连续**：服装、妆发、道具、伤痕、时间和天气变化有记录。
7. **技术可交付**：画幅、时长、字幕区域和输出规格已确认，或明确标为待核实。
8. **权利可信**：音乐、影像、字体、真实人物、商标和改编素材状态清楚；未知项不得伪装成已授权。
9. **风险透明**：高成本、高风险、不可控和需要专业复核的事项已单列。
10. **来源可追溯**：外部事实、教程、平台规则不伪造出处；不把猜测写成事实。

## 2. 质量评分

每项 1–5 分。达到 4 分以上才算可用。

| 维度 | 4 分标准 |
|---|---|
| 剧本忠实度 | 保留原作意图，变更可追踪 |
| 叙事清晰度 | 观众能跟上人物目标、信息和转折 |
| 视觉具体度 | 颜色、光线、镜头、构图、材质可执行 |
| 连续一致性 | 角色、场景、道具和时空无明显冲突 |
| 制作可行性 | 风险与替代方案明确，资源依赖可被识别 |
| 风格统一性 | 镜头选择共同服务同一视觉命题 |
| 声音与剪辑 | 转场、节奏、音乐和环境声有叙事理由 |
| 合规与权利 | 不把未知风险包装成已解决 |
| 直接可用性 | 制作人员无需反复猜测即可进入下一步 |

总分不是唯一标准。任何硬性项失败都不能用高分抵消。

## 3. 一级失败：不可交付

- 把梗概当完整剧本，凭空声称已理解未出现的内容；
- 静默改写核心结局或人物动机；
- 风格方向有多个强分支却未询问用户就生成最终分镜；
- 镜头表只有“远景/近景/特写”，没有动作、声音和执行信息；
- 镜头在空间、轴线或时间上无法衔接；
- 人物外观、关键道具或伤痕跨场无故变化；
- 角色/场景/风格在镜头之间互相冲突；
- 使用未授权音乐、影视片段、字体、真实人物肖像或声音，却标为可交付；
- 对平台过审、法律、预算或档期作无依据保证；
- 把外部教程整段复制或伪造引用来源。

## 4. 二级失败：需返工

- 分镜完整但镜头重复，信息没有递进；
- 每场都有内容，但集尾缺少下一步问题或情绪拉力；
- 视觉风格统一但成本明显超出已知资源；
- 转场只靠叠化、白闪或黑场，缺少内容连接；
- 字幕、构图或画幅未考虑竖屏安全和平台 UI；
- 台词把画面已经表达的信息重复一遍；
- 声音没有场景空间和环境层次；
- AI 提示词只堆关键词，没有动作和连续性；
- 制作清单存在，但没有把风险映射回具体镜头。

## 5. 自检方法

### 反读测试

从最后一个镜头倒着读，确认观众能否重建因果链。若必须依赖未拍出的解释，补镜或改文本。

### 盲拍测试

只看某一镜的镜头卡，假设制作人员没看全剧本：能否知道机位、开始动作、结束动作和声音？

### 场景删除测试

删掉一场后，故事是否仍然成立。如果成立，这场可能缺少不可替代的功能；如果不成立，能否一句话说清它的必要性？

### 替代方案测试

把最高风险镜头替换成最低成本方案，故事是否仍清楚？若不清楚，风险镜头就是叙事核心，应优先保障，而不是最后才处理。

### 权利来源测试

每个外部素材能否回答：来自哪里、谁授权、允许什么用途、凭证在哪里、何时核验？答不出就标为 `[需核实]`，不能写“可商用”。

## 6. 最终自评格式

```text
交付结论：可执行 / 条件性可执行 / 需返工
硬性检查：通过 X/10；未通过项
评分：忠实度 x/5；叙事 x/5；视觉 x/5；连续性 x/5；可行性 x/5；统一性 x/5；声音剪辑 x/5；合规 x/5；可用性 x/5
最重要的三个风险：
待用户确认：
下一步建议：
```

只有所有硬性项通过、相关维度不低于 4/5，且没有未关闭的风格闸门，才能写“可执行”。
