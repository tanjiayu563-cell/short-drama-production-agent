# 小说改编：画面、旁白、人物关系与镜头节奏

## 1. 先做“呈现方式”判断

小说句子不等于镜头。处理选中区域时，先把每个信息单元分成：

- 可见动作；
- 对白；
- 内心活动；
- 背景说明；
- 关系变化；
- 声音信息；
- 文字/屏幕信息；
- 空间与物件信息。

然后为每个单元选择呈现方式：

| 呈现方式 | 适合的信息 | 不应做什么 |
|---|---|---|
| 画面动作 | 动作、身体反应、空间关系、物件变化 | 不让旁白重复画面已经说清的内容 |
| 对白 | 人物当面说话、冲突、试探、交换信息 | 不把小说叙述全改成人物台词 |
| 旁白 / VO | 无法可见化、但必须保留的信息 | 不用旁白解释观众已经看见的动作 |
| 表演 | 恐惧、犹豫、压抑、怀疑、亲密、权力变化 | 不用夸张表情替代具体动作 |
| 画外声 | 门外、背后、远处、未知空间 | 不先展示声源，再假装声音制造悬念 |
| 文字插入 | 手机、短信、信件、合同、订单、照片、日记 | 不让生成模型承担精确可读中文 |
| 道具 / 环境 | 身份、时间、地点、过去痕迹、关系暗示 | 不把道具只当装饰 |
| 省略 | 重复信息、无视觉价值、可被动作替代的解释 | 不为了保留原文而逐句翻译 |

### 默认优先级

1. 能用动作和空间表达时，用画面；
2. 能通过人物反应表达时，用表演；
3. 能用声音制造空间时，用画外声；
4. 必须保留的抽象信息才用短旁白；
5. 文字类信息优先后期合成；
6. 同一信息只承担一种主要呈现方式。

## 2. 旁白判定

### 可以保留旁白

- 时间跨度，无法通过一场戏完整展示；
- 叙述者才掌握、画面无法表达的过去信息；
- 信息密度高，但画面插入会造成节奏断裂；
- 主观记忆与客观画面存在明显差异；
- 原著第一人称叙述的口吻本身是作品魅力。

### 应删除或改写旁白

- “他很害怕”“她很生气”等可以直接表演的心理总结；
- “他走进房间，打开门”等画面已经完成的动作；
- 与对白重复的信息；
- 为解释镜头而补写的说明；
- 把小说每句话逐句转成 VO。

### 旁白写法

一句话只承担一个新信息。优先短句、留白和具体名词，少用抽象总结。

## 3. 人物关系图

每个选区先建立角色关系，不是全书静态关系表。记录：

```text
角色 A：
角色 B：
关系称谓：
当前场景的关系状态：
权力位置：
信任程度：
隐瞒信息：
身体距离：
关系变化：
证据 / 原文依据：
可信度：明确 / 推断 / 待确认
```

关系不只包括亲属，还包括：

- 权力：支配、服从、保护、控制；
- 情感：亲近、依赖、怨恨、愧疚、爱慕；
- 信息：谁知道什么、谁在隐瞒；
- 经济：债务、雇佣、利益交换；
- 空间：谁站在门内、谁在门外、谁被允许进入。

### 用画面表现关系

- 双人距离、站位高低、谁挡住出口；
- 过肩镜中的遮挡比例；
- 同框/不同框、共享画面空间；
- 视线方向和谁先移开；
- 谁持有钥匙、手机、票据、武器或遗物；
- 第三方是否隔开两人；
- 门、桌、门链、车窗等物理阻隔；
- 沉默、停顿和背景声音。

不要只让角色说“我是你爷爷”“我们是朋友”来解释关系。

## 4. 镜头去重复

每个节拍先标记功能：

- 建立空间；
- 推进动作；
- 揭示信息；
- 人物反应；
- 表现关系；
- 制造悬念；
- 转场；
- 收束。

### 基本规则

- 不连续三个节拍使用同一景别；
- 不把每句对白都拍成同一种近景；
- 一场戏至少包含三种不同功能镜头；
- 每次运镜必须有叙事动机和明确落幅；
- 固定机位不是“单调”，乱推拉才是；
- 重复构图只有在表达重复、宿命或关系闭环时才使用；
- 同一信息不要同时用画面、对白和旁白解释三遍。

### 镜头选择池

| 节拍功能 | 优先镜头 |
|---|---|
| 建立空间 | 远景、全景、环境插入 |
| 推进动作 | 全景、中景、侧面跟随、插入镜 |
| 揭示信息 | 大特写、手部、屏幕/纸张插入 |
| 人物反应 | 近景、特写、浅景深侧后方 |
| 表现关系 | 双人中景、过肩、隔门构图、负空间 |
| 制造悬念 | 声源特写、门缝、背影、画外空间 |
| 转场 | 动作匹配、声音桥、物件特写、遮挡转场 |

## 5. 场景节拍表

```text

```

## 6. 自检

- 如果关闭旁白，故事是否仍能看懂？
- 如果关闭画面，旁白是否只是在重复台词？
- 关系是否能从站位、距离和视线看出来？
- 不同节拍是否承担了不同叙事功能？
- 每三个连续镜头中，是否至少有一个景别或机位变化？
- 是否有一个镜头只是为了“好看”而没有功能？
