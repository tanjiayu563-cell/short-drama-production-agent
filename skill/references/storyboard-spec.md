# 分镜设计规范

## 1. 分镜的最小单位

一个镜号 = 一个连续取景单元。发生剪切、明显时间跳跃或新的独立视点，就新建镜号。镜内运镜、变焦或焦点转移仍是同一镜，但必须在运动栏写清起幅、过程与落幅。

分镜不是把台词逐句配画面。每个镜头至少要承担一种功能：

- 推进动作；
- 揭示信息；
- 建立空间；
- 表达人物状态或关系；
- 制造悬念、期待或误判；
- 控制情绪节奏；
- 完成动作或视线的转场。

如果一个镜头没有任何功能，合并或删除。

## 2. 场景分镜表

每个场景先写场景目的，再列镜头。

```text
场次：
地点 / 时间：
场景目的：
人物目标与阻力：
信息变化：
情绪起点 → 情绪终点：
空间与轴线示意：
预计镜头数 / 时长：
```

紧凑表建议字段：

| 镜号 | 时长 | 功能 | 景别 | 角度/机位 | 运作/焦段 | 画面动作 | 台词/旁白 | 声音 | 转场 | 连续性 |
|---|---|---|---|---|---|---|---|---|---|---|

复杂镜头再补充镜头卡。不要让紧凑表替代关键镜头的完整设计。

## 4. 镜头语言选择

### 景别

按信息量选择，不按“越高级越好”：

- 大远景：地理、孤立、规模、时代；
- 远景：人物与空间关系、行动路线；
- 全景：完整身体动作、关系位置、构图；
- 中景：对话、肢体关系、日常动作；
- 中近景：表情与手势并重；
- 近景：情绪、判断、信息反应；
- 特写：物件、细节、强情绪、线索；
- 大特写：局部细节或压迫性主观感受。

### 角度与机位

说明选择带来的权力与情绪：

- 平视：中性、平等、观察；
- 仰拍：权力、威胁、崇高；
- 俯拍：脆弱、受困、全局；
- 荷兰角：失衡、危险、精神压力；
- 过肩：关系与对话位置；
- 主观视角：限制信息和增强代入；
- 高机位俯视桌面/地面：线索与空间调度。

### 焦段与景深

焦段是空间关系设计，不只是“虚化程度”：

- 广角：空间纵深、环境压迫、动作范围、透视夸张；
- 标准：接近自然观察；
- 中长焦：压缩空间、隔离人物、突出面部；
- 长焦：远距离观察、背景压缩、偷窥感；
- 浅景深：隔离主体、隐藏环境；
- 深景深：人物与环境同时发声、群像关系。

不要让每个镜头都使用最大虚化。关键线索、空间关系和群像可能需要清楚背景。

### 运镜

写清运动动机和起落点：

- 固定；
- 摇；
- 移；
- 跟；
- 升降；
- 推/拉；
- 手持；
- 斯坦尼康/稳定器；
- 轨道/滑轨；
- 变焦或焦点转移。

避免“炫酷运镜”。说明它揭示什么、跟随谁、在哪里结束，以及没有稳定器或轨道时的替代方案。

## 5. 构图与调度

至少检查：

- 主体在画面中的位置和视线留白；
- 前中后景是否提供层次或信息；
- 门窗、走廊、桌面、镜面是否形成框架；
- 引导线是否把视线带向叙事重点；
- 人物距离是否对应亲密、权力或威胁；
- 背景是否有干扰或叙事活动；
- 竖屏构图是否保留头部、手部、关键道具和字幕安全区；
- 横屏构图是否有足够的左右调度空间；
- 切到下一镜时，观众是否能快速定位新空间。

同一场景的轴线、视线和银幕方向应稳定。需要越轴时，用中性镜头、人物移动、主观镜或明确空间建立来完成。

## 6. 灯光与色彩写法

写具体，不写“氛围感”：

```text
主光：方向 / 软硬 / 色温倾向 / 高度
辅光：比例与作用
轮廓光：是否使用 / 目的
实用光：来源 / 位置 / 是否入画
背景光：层次 / 色差
光比：低 / 中 / 高，以及人物哪侧亮
色板：主色 / 辅色 / 强调色 / 肤色
饱和度：低 / 中 / 高，偏冷或偏暖
对比度：黑位、高光、阴影细节
空气感：雾、尘、烟、雨、蒸汽等是否有动机
```

灯光变化必须有叙事原因，如时间变化、光源被打开、人物进入阴影或情绪转折。

## 7. 声音与剪辑

每场设计声音层次：

- 对白与停顿；
- 画外音和主观声；
- 环境底；
- 动作拟音；
- 音乐进入/退出点；
- 静默；
- 声音桥。

转场优先考虑内容连接：动作匹配、视线匹配、形状匹配、声音先行、遮挡、物件特写、时间跳切。叠化、白闪和花哨特效必须有叙事理由。

字幕设计要考虑画面负空间、说话人、道具文字和平台 UI。没有核验当前平台规格时，不要写死安全区像素；写明“需按当前平台规格核验”。

## 8. 连续性检查

逐场逐镜检查：

- 人物位置、朝向、视线和银幕方向；
- 动作接续与手部/道具所在侧；
- 服装、发型、妆面、伤痕、污渍和湿度；
- 食物、饮料、烟、手机电量/屏幕等消耗或变化；
- 时间、天气、光线方向、阴影和背景活动；
- 镜面、照片、屏幕文字与反射；
- 谁在场、谁听见、谁看见；
- 台词称谓、关系和信息状态。

将连续性风险写进镜头卡，不留给现场猜测。

## 9. AI 视频镜头写法

提示词按以下顺序组织：

```text
一致性引用：角色卡 / 场景卡 / 道具卡
主体与外观：谁，什么状态，服装与关键特征
动作：一个可执行的连续动作，写清开始与结束
环境：地点、时间、天气、背景活动
光影与色彩：方向、软硬、色板、饱和度、材质
镜头：景别、角度、焦段、构图、运镜
节奏：动作速度、镜头停留、转场衔接
必须保持：脸、发型、服装、道具、方向
负面约束：不要新增人物、不要改变服装、不要多余手指等
```

把复杂动作拆成多个镜头，不要要求单个生成片段完成过多事件。精确口型、连续对白、精细手部操作和屏幕文字应标为高风险，并给出后期或实拍方案。

## 10. 示例：只展示颗粒度

以下示例是虚构片段，用于说明字段，不是固定风格。

```text
镜号：S02-04
时长：约 3 秒（建议值，需按剪辑实际调整）
功能：林岚发现钥匙不见，推动她返回办公室
景别：中近景转手部特写
角度/机位：平视，略偏林岚右侧，桌面高度
镜头：50mm，浅景深；固定后跟随她低头，焦点从脸转到空桌面
构图：林岚在右三分线，左侧留出门口空间；空桌面位于画面下方中心
动作：她把包翻过来，手指停住；视线扫向桌面缺口
表演：呼吸变浅，先不信，再确认；不立即说台词
声音：包链声、纸张摩擦；环境空调声突然变低
转场：切到门口保安的过肩镜，声音先行
连续性：钥匙上一场在黑色内袋；右手拿包；桌面咖啡杯位置不变
备选：若无焦点转移设备，切手部插入镜
```

## 11. 完成标准

分镜至少要能回答：

- 拍摄/生成的人知道每镜从哪里开始、到哪里结束；
- 演员知道动作和情绪节拍；
- 美术知道场景、道具和颜色要求；
- 灯光知道方向和对比；
- 剪辑知道镜头的意图与衔接；
- 制作者知道哪一镜最贵、最难、最容易失败；
- 用户知道哪些内容是原设定、建议或待确认。
