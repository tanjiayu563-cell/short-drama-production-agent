# 外部资料、版权与事实核验

## 1. 允许建立什么样的“教程库”

可以建立：

- 来源链接和书目信息；
- 发布日期、访问日期、适用范围；
- 原创摘要；
- 必要且简短的引用；
- 方法论标签；
- 可信度和时效性备注；
- 授权状态与使用限制。

不要批量保存或重新分发：

- 受版权保护的整篇文章、课程、视频、字幕或教材；
- 付费内容；
- 禁止抓取或禁止再利用的页面；
- 未经许可的影视片段、音乐、字体、图片和声音。

“互联网可访问”不等于“可以复制、商用或二次分发”。采集前检查网站条款、robots 限制、许可协议和素材来源。

## 2. 来源优先级

1. **法律法规、监管机构、平台官方规则**：用于合规、技术规格和发布要求。
2. **一手制作资料**：拍摄手册、摄影机/灯具/软件官方文档、公开的幕后制作资料。
3. **专业教材、行业组织、可信影视教育机构**：用于镜头、灯光、剪辑、声音等通用方法。
4. **高质量创作者教程**：用于技巧和工作流参考，需要交叉验证。
5. **论坛、短视频、个人经验**：只作为灵感或问题线索，不能直接当规则。

教程讲的是方法，不是绝对真理。不同画幅、类型、预算和平台可能得出不同结论。

## 3. 外部事实核验格式

```text
结论：
来源标题：
发布者 / 作者：
发布日期：
访问日期：
链接：
适用范围：
原文证据：简短引用或转述
可信度说明：官方 / 一手 / 二手 / 社区
时效风险：
```

无法打开来源、无法确认作者或无法确认适用地区时，使用 `[需核实]`。不要编造访问日期、条款编号、价格或平台阈值。

## 4. 平台与法规类信息

只有在来源可核验时才写成要求：

- 写明适用平台、地区、账号类型和内容类型；
- 核对发布日期和当前版本；
- 区分“平台建议”和“法律要求”；
- 区分“发布规范”“技术规格”“内容审核”和“商业分账”；
- 对可能变化的阈值提供核查路径，不写死过期数字；
- 不承诺过审、流量、收益或账号安全。

涉及合同、版权、名誉权、隐私、真实人物、未成年人和敏感内容时，给出专业复核提醒，不冒充律师或平台审核人员。

## 5. 素材权利清单

每个外部素材记录：

```text
素材名称：
类型：音乐 / 影像 / 图片 / 字体 / 声音 / 剧本 / 商标 / 其他
来源：
作者 / 权利人：
获取方式：
许可类型：
允许用途：商业 / 非商业 / 改编 / 地域 / 期限
署名要求：
凭证位置：
核验日期：
风险备注：
```

常见状态：

- `已授权`：有可追溯的授权条款或凭证；
- `公共领域`：需确认适用地区和作品状态；
- `开放许可`：需遵守署名、相同方式共享等条件；
- `平台内可用`：仅限该平台或特定场景时，不要跨场景复用；
- `需核实`：未确认，不得当作用户可直接商用的素材；
- `禁止使用`：权利或平台规则明确不允许。

## 6. 风格参考与真人参考

用户给出参考片、导演、摄影师或艺术家时：

- 先拆成可观察属性：构图、镜头、色彩、光线、材质、剪辑、声音、表演；
- 区分“受其方法论启发”和“复制具体作品”；
- 不使用在世艺术家的名字作为 AI 生成的一键风格替代；
- 不生成可识别真实人物的虚假代言、私密场景、违法指控或欺骗性内容；
- 真实人物肖像、声音和经历需要相应授权和专业审查。

## 7. 预算与档期

没有可核验报价时，只给成本驱动和复杂度，不编造金额或天数。

可以写：

```text
成本等级：中
主要驱动：夜外、雨效、稳定器、双机位、后期擦除
可降本方案：改为日內、固定机位、用声音暗示雨夜
待确认：场地报价、灯光租赁、人员日薪、后期工时
```

不能写：

```text
预算一定是 5 万元，3 天拍完，平台一定过审。
```

除非用户提供了可验证数据和对应条件。

## 8. 知识库维护

每次使用外部资料后，可按主题更新索引：

```text
主题：
适用阶段：剧本 / 视觉 / 分镜 / 灯光 / 剪辑 / 声音 / 平台 / 权利
核心方法：
不适用条件：
来源：
最后核验：
```

规则类资料比教程类资料更频繁失效。发布前、报价前和涉及当前平台政策时重新核验，不把旧笔记当现状。

## 9. 引用与独立性

- 用自己的话整合方法，不把教程文本拼接成“原创知识库”。
- 引用短句时加引号和出处；无来源时说明是自己的创作建议。
- 多个来源冲突时，列分歧、适用条件和当前证据，不强行合成唯一答案。
- 用户提供的事实与外部来源冲突时，指出冲突、依据和风险，再给出更合理的解释。
