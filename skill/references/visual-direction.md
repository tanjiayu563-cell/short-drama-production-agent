# 视觉方向与 Style Lock

## 1. 风格不是形容词集合

“电影感、高级、唯美、暗黑、赛博”只有落到可执行的视觉变量才有意义。至少同时定义：

- 叙事温度：冷峻、亲密、荒诞、浪漫、压迫、怀旧等；
- 写实程度：纪实、自然主义、类型化、强风格化、动画化；
- 时代和地域：服装、建筑、器物、语言与技术要自洽；
- 镜头语法：静态/手持、长镜/碎切、广角/长焦、客观/主观；
- 光影：硬/软、高/低对比、自然/人造、方向与动机；
- 色彩：主色、辅色、肤色策略、饱和度、对比度、黑位、高光；
- 材质：干净、颗粒、柔光、旧化、塑料感、胶片感、数字锐度；
- 剪辑：节奏、跳切、匹配剪、叠化、遮挡转场、时间重排；
- 声音：环境密度、音乐功能、静默使用、主观声、混响空间；
- 表演：克制/外放、自然/程式化、喜剧节拍、身体控制；
- 制作规模：场景数、特殊器材、动作、VFX、群演和天气依赖。

## 2. 风格方案闸门

当存在两个或更多实质不同、都可服务剧本的方向时，必须给出 2–3 个完整方案并停下询问。

每个方案使用以下字段：

```text
方案名：
一句话视觉命题：
为什么适合这个故事：
色彩与影调：主色/辅色/饱和度/对比度/肤色/黑位/高光
画面材质与镜头：画幅/焦段倾向/景深/机位/运动/构图
人物与服化道：
场景与美术：
剪辑与声音：
代表镜头（2–3 个，写清画面而非只写关键词）：
制作优势：
成本与执行风险：
最不适合的情况：
```

最后给出推荐，但不替用户决定：

```text
我的推荐：A
理由：
代价：
请选择 A / B / C，或说明希望混合的部分。确认前不生成最终分镜。
```

每个主要人物建卡：

```text

面部锚点：
发型与发色：
体型与姿态：
皮肤与妆面：
基础服装：
标志性配件：
色彩归属：
常用镜头景别：
行为习惯：
声音与语速：
情绪外显方式：
故事前后的允许变化：
不可变化的一致性锚点：
AI 角色约束（如适用）：
```

人物设计服务于角色功能和关系，不要只追求“好看”。用服装轮廓、颜色、材质和配件传达阶层、职业、状态与变化。

```text

前中后景：

关键道具：
```

关键道具至少定义：外观、尺寸、磨损、存放位置、由谁持有、何时改变、是否承担叙事信息。

## 6. 视频与 AI 生成注意

- 先锁定镜头功能，再写生成提示词。
- 提示词应描述可见事实，不依赖模型理解抽象情绪。
- 跨镜头一致性依靠角色卡、服装卡、场景卡、光线方向和动作衔接，而非重复同一串关键词。
- 明确哪些镜头不适合生成：复杂手部互动、精确口型、连续动作、屏幕文字、镜子反射、多人遮挡、复杂道具转移等；给出实拍或后期替代。
- 不要把在世艺术家的名字当作风格提示词。将参考拆成构图、色彩、光线、材质、镜头和剪辑属性；如平台或法律要求，进一步移除姓名并记录授权状态。
