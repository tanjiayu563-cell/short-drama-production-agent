# Seedance 视频提示词适配

## 1. 已核实信息

以下信息来自字节跳动 Seed 官方页面与本项目访问记录：

- Seedance 2.0：采用统一的多模态音视频联合生成架构，支持文字、图片、音频、视频四种输入；强调运动稳定性、物理规律、原生音画同步和多模态参考/编辑。
- Seedance 2.5：官方称支持单次 30 秒生成和两次视频延长；支持最多 30 张图片、10 段视频、10 段音频作为参考；支持时间戳控制、绿幕编辑、视角/运镜编辑和参考编辑。
- 官方 2.5 发布文章同时指出：复杂运动物理合理性和极多主体交互稳定性仍有提升空间。

来源：

- Seedance 2.0：<https://seed.bytedance.com/zh/seedance2_0>，访问日期 2026-11-02；
- Seedance 2.5：<https://seed.bytedance.com/zh/seedance2_5>，访问日期 2026-11-02；
- 《一镜成片，随心参考｜Seedance 2.5 正式发布》：<https://seed.bytedance.com/zh/blog/one-take-creation-flexible-referencing-introducing-seedance-2-5>，发布日期 2026-07-31，访问日期 2026-11-02。

平台 UI、API 和地区版本可能不同。实际参数名、参考数量、支持时长和音频能力应在使用前重新核验，不要把本文当作 API 文档。

## 2. 先选择生成任务

每个镜头先标记任务类型：

| 类型 | 输入 | 目标 |
|---|---|---|
| T2V | 文本 | 生成完整镜头 |
| I2V | 单张首帧/参考图 + 文本 | 控制角色、构图或起始状态 |
| R2V | 多图片/视频/音频参考 + 文本 | 复用角色、场景、动作、声音或风格 |
| Extend | 已有视频 + 文本 | 延续动作、场景和音频 |
| Edit | 已有视频 + 编辑说明 | 只改变指定时间段或指定元素 |
| V2V | 视频参考 | 迁移或重演动作、镜头语言、结构 |

不要用同一个提示词结构硬套所有任务。编辑任务必须写清“保持什么、改变什么、改变发生在哪个时间段”。

## 3. Seedance 提示词结构

### 通用镜头提示词

```text
任务：T2V / I2V / R2V / Extend / Edit
画幅：竖屏 9:16（按当前产品核验）
目标时长：{{秒数}}

主体：
{{角色身份、年龄感、发型、服装、关键外观锚点}}

起始状态：
{{镜头开始时人物位置、姿态、道具、光线、环境状态}}

连续动作：
{{按动作阶段描述，从开始到结束；只保留可在一个连续镜头内完成的动作}}

结束状态：
{{人物的最终位置、姿态、表情和关键道具状态}}

环境：
{{地点、时间、天气、前中后景、背景活动}}

光影与色彩：
{{主光方向、软硬、色温、主色、辅色、饱和度、对比度、材质}}

镜头：
{{景别、机位高度、角度、焦段倾向、构图、运镜方式与起止位置}}

声音：
{{对白、环境声、拟音、音乐、静默；无声音则明确写“无音乐”}}

连续性：
{{人物、服装、道具、空间、动作、光线必须保持不变的部分}}

禁止：
{{不要新增人物、不要改变服装、不要额外字幕/Logo、不要出现...}}
```

### 多模态参考写法

如果当前产品支持 `@图片1`、`@视频1`、`@音频1` 或白模引用语法，先给每份素材分配唯一角色：

```text
@图片1：林夏的角色外观锚点，仅参考脸、发型和灰色针织衫，不参考背景。
@图片2：室内场景锚点，仅参考空间布局、台灯位置和色彩，不参考人物。
@视频1：只参考镜头运动和节奏，不复制人物与场景。
@音频1：只参考雨声音色，不复制可识别音乐旋律。
```

原则：

- 一份素材只承担一个主要职责，减少冲突；
- 不要把角色参考、风格参考和动作参考混在同一张图里；
- 参考素材中的文字、Logo、水印和不希望保留的元素要明确排除；
- 素材需要有来源和权利状态，不能把“网上可访问”当作可商用。

## 4. Seedance 2.5 的时间分段写法

当镜头内部存在多个清晰节拍，使用时间戳描述，但不要把一个短镜头塞入过多事件：

```text
0–3 秒：手机屏幕亮起，林夏拇指停在备注上；镜头保持固定，只有雨声和消息提示。
3–7 秒：林夏抬头，呼吸停半拍，缓慢转向左侧的门；镜头轻微向前推近。
7–12 秒：她走到门边，先挂上门链，再贴近猫眼；镜头跟随半步后停住。
```

每个时间段至少写清：

- 谁在做什么；
- 摄影机是否变化；
- 场景或声音是否变化；
- 该段结束时必须到达什么可见状态。

时间分段是制作约束，不代表模型会自动严格按时间执行。生成后仍要逐段核验。

## 5. 长视频与延长写法

```text
延长 @视频1，保持同一人物外观、服装、场景布局、画面风格、光线方向和声音空间感。
上一段结束状态：{{角色位置、朝向、手中道具、动作进度}}。
本段开始状态必须与上一段连续：{{动作接续}}。
本段故事节拍：{{0–...秒}}。
本段结束状态：{{下一步动作或悬念}}。
不要重置人物位置、不要换装、不要新增未声明角色、不要突然改变光影方向。
```

延长前先检查上一段末帧。若末帧人物朝向、手部位置或道具状态不稳定，不要直接延长；先用更短镜头或后期剪辑修正。

## 6. 编辑写法

```text
编辑 @视频1。
保持：人物身份、面部、发型、服装、身体比例、动作节奏、原场景、原光线、原声音。
改变：只调整 {{指定时间段}} 的 {{摄影机运动/背景/道具/声音}}。
目标：{{可观察结果}}。
边界：不改台词、不新增角色、不改变镜头顺序、不改变人物最终位置。
```

绿幕或视角编辑时，明确新环境的物理规则：衣服飘动、头发、步态、阴影方向和地面接触必须随新场景变化。

## 7. 不适合直接交给 Seedance 的内容

这些镜头不是绝对不能生成，而是需要拆分、参考素材或后期替代：

- 复杂手部和多指交互；
- 精确口型、长对白或多人同时说话；
- 需要精确可读的中文屏幕文字、合同、弹幕和标题；
- 镜子、玻璃、水面反射中的多主体一致性；
- 多个角色复杂遮挡、交接道具和快速动作；
- 在同一镜头内完成多次身份变化或时空跳跃；
- 极高精度物理互动、武打、车辆碰撞和危险特技。

给每个高风险镜头准备一个更可控的替代方案，例如：

- 拆成两个短镜头；
- 用插入镜和声音暗示动作结果；
- 屏幕文字后期合成；
- 口型用侧背身、反应镜或 ADR；
- 危险动作改用替身、道具或画外空间。

## 8. Seedance 提示词重写规则

生成失败后，不要只在原提示词末尾追加“更好、更真实、不要失败”。先定位原因，再选择一种主要修改：

| 失败原因 | 首选修改 |
|---|---|
| 主体身份漂移 | 增加清晰的单角色参考，减少同镜角色数，缩短动作 |
| 动作没完成 | 把动作拆成起、中、止三个可见状态，减少并行事件 |
| 镜头运动错误 | 把运镜简化为一种运动，写清起幅和落幅 |
| 场景重置 | 明确空间锚点、人物初始位置和上一段末帧状态 |
| 声音不同步 | 缩短对白，拆成反应镜，或后期配音 |
| 物理不合理 | 避免复杂接触，改用局部特写、声音或后期 |
| 风格漂移 | 减少风格形容词，锁定材质、色板、光源和镜头参数 |

每次迭代只改变一个主要变量：提示词、参考素材、时长、镜头拆分或模型版本。否则无法判断是哪项改动带来变化。
