# 制作交接与风险管理

## 1. 从分镜反推制作清单

逐场汇总，不要只列“需要道具”。

### 人物与表演

- 角色、年龄段、主要戏量；
- 特约、群演、替身；
- 服装套数、换装点、污损/湿度变化；
- 妆发、伤痕、泪痕、汗、年龄变化；
- 亲密戏协调、未成年人监护；
- 动物训练员或专业人员；
- 口音、方言、歌唱、乐器、动作技能。

### 场景与美术

- 内外景、时段、天气；
- 场景数、转场距离、可拍时段；
- 陈设、消耗品、屏幕内容、品牌露出；
- 背景活动与群众演员；
- 场地许可、噪音、邻居、公共空间拍摄；
- 消防、用电、高空、水域、道路等安全要求。

### 摄影与器材

- 画幅与帧率；
- 焦段、特殊镜头、微距、长焦；
- 稳定器、轨道、摇臂、灯光、控光；
- 雨、烟、风、火、水、碎屑等特效；
- 监视、备份、电池、存储；
- 需要测试的焦点转移、反射、屏幕和高速镜头。

### 声音与音乐

- 同期声、后期配音、ADR；
- 不可控噪音与备选时段；
- 拟音需求；
- 音乐风格、进退出点、是否必须原创/授权；
- 静默和声音桥；
- 版权状态与授权凭证。

### 后期与交付

- 剪辑版本与时长；
- 调色依据、LUT/色彩管理；
- 字幕、标题、片尾、字体授权；
- 视觉特效、合成、擦除；
- 混音、响度、平台规格；
- 竖屏/横屏、封面、预告、切片版本；
- 归档与命名。

## 2. 复杂度分级

不虚报金额或天数。用 `低 / 中 / 高` 标出成本与执行驱动，并说明原因。

| 维度 | 低 | 中 | 高 |
|---|---|---|---|
| 场景 | 单一固定场景 | 少量场景切换 | 多场景、多地、跨时段 |
| 人物 | 1–2 人 | 小组对话 | 群像、群演、儿童/动物 |
| 摄影 | 固定或简单手持 | 稳定运镜、少量特殊镜头 | 复杂调度、长镜头、特殊器材 |
| 灯光 | 自然光或简单补光 | 控制光比与实用光 | 日夜转换、雨夜、复杂光效 |
| 动作/特效 | 无 | 简单动作或合成 | 特技、烟火、水、车辆、复杂 VFX |
| 后期 | 基础剪辑调色 | 字幕、混音、少量修复 | 大量合成、口型、换脸、精细声音设计 |

成本驱动要写成“什么会变贵”，例如：“夜外雨戏同时推高灯光、发电、防水、场地和后期擦除成本”，不要只写“预算高”。

## 3. 分场计划

```text
场次：
地点：
预计拍摄顺序：
人物：
关键道具：
特殊器材：
动作/特效：
声音要求：
天气/时段：
许可与安全：
前置依赖：
预计复杂度：低 / 中 / 高
替代方案：
```

优先按场景、光线和演员档期合并拍摄，但不要为省成本破坏关键连续性。标出哪些镜头可以合并、哪些必须连拍。

## 4. 风险矩阵

按“发生可能性 × 影响”排列：

| 风险 | 触发条件 | 影响 | 预防 | 发生后的替代方案 | 负责人/待确认 |
|---|---|---|---|---|---|

常见风险：

- 版权、商标、音乐、字体、素材授权不清；
- 真实人物、肖像、声音、隐私、名誉；
- 未成年人、亲密戏、暴力、危险行为；
- 天气、场地、设备、演员档期；
- 竖屏安全区、字幕遮挡、平台技术规格；
- 角色形象跨镜头不一致；
- AI 生成的手、口型、文字、反射和动作错误；
- 分镜过于复杂但预算/周期不足；
- 台词信息与画面信息互相打架。

## 5. 替代方案规则

每个高风险镜头至少给一个更易执行的替代方案：

- 复杂运镜 → 固定机位 + 分段剪辑；
- 大场面 → 局部特写 + 声音暗示；
- 精确口型 → 侧背身 + 反应镜 + 后期配音；
- 危险动作 → 替身、道具、暗示、画外空间；
- 不受控天气 → 改光线动机、换室内或后期；
- 角色一致性不稳 → 固定机位、短动作、少遮挡、角色参考卡；
- 多场景成本高 → 合并空间或把转场写成声音/物件桥。

替代方案不能只写“后期解决”。要说明素材如何拍、声音如何补、需要哪个部门。

## 6. 文本交付命名

建议使用稳定、可排序的命名：

```text
项目名_版本_日期_制作包.md
项目名_场景表.md
项目名_分镜表.md
项目名_人物场景卡.md
项目名_风险与替代方案.md
```

若用户指定文件名、表格格式或制作管理系统，优先遵从。导出前确认 UTF-8、中文字体和表格宽度在目标工具中可读。
