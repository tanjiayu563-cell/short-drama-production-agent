# 生成视频质检与迭代

## 1. 目标

判断生成视频是否真正满足镜头任务，而不是只看“漂亮不漂亮”。质检必须同时回答：

1. 它是否符合原分镜和提示词？
2. 是否具备可剪辑、可接戏的技术质量？
3. 失败原因是什么？
4. 应该改提示词、参考素材、参数、镜头拆分，还是直接采用后期/实拍替代？
5. 下一版应改哪一个主要变量？

没有看到实际视频、关键帧或可靠画面描述时，不得声称已完成质检。

## 2. 输入

优先要求：

- 原分镜镜头卡；
- 实际发送给模型的完整提示词和负向约束；
- 模型名称、版本、参数、参考素材；
- 视频文件或关键帧；
- 本镜验收标准；
- 上一版视频/提示词，用于对比。

缺失时明确写出无法判断的项，不要补脑。

## 3. 质检流程

### 第一步：技术检查

- 时长、画幅、分辨率、帧率；
- 是否有音频轨；
- 黑帧、冻结帧、明显花屏；
- 文件能否正常解码；
- 是否需要裁切、补帧、重新封装；
- 画面文字、Logo、水印和字幕是否出现。

可使用：

```bash
python3 scripts/video_qc.py INPUT.mp4 \
  --out work/qc-shot-001 \
  --target-ratio 9:16 \
  --target-duration 6
```

脚本只负责提取元数据、关键帧和联系表，并做基础技术检测。语义质检必须由 Agent 查看关键帧/联系表后完成。

### 第二步：画面完整性

逐项检查：

- 主体是否完整入画；
- 头顶、手部、关键道具是否被裁切；
- 竖屏主体位置是否合理；
- 焦点是否落在叙事重点；
- 前景是否遮挡面部或动作；
- 构图是否保留字幕与平台 UI 的潜在空间；
- 镜头结束是否有足够可剪余量。

### 第三步：提示词遵循

把原始镜头任务拆成可观察条件，逐项填“通过/部分/失败”：

| 条件 | 证据 | 结果 |
|---|---|---|
| 主体身份与外观 |  |  |
| 起始状态 |  |  |
| 关键动作 |  |  |
| 结束状态 |  |  |
| 景别与机位 |  |  |
| 运镜方式 |  |  |
| 构图 |  |  |
| 光影与色板 |  |  |
| 场景与背景活动 |  |  |
| 声音 / 静默 |  |  |
| 连续性 |  |  |
| 禁止项 |  |  |

“画面好看但动作不对”仍属于失败。

### 第四步：时间与连续性

逐段检查：

- 人物身份是否发生漂移；
- 脸部、手部、身体比例是否变形；
- 服装、发型、配饰是否变化；
- 道具数量、位置、持握侧是否变化；
- 视线、朝向和银幕方向是否跳变；
- 动作是否跳帧、倒退、重复或未完成；
- 背景是否闪烁、融化、重建或出现多余人物；
- 光线方向和色温是否突然改变；
- 镜头运动是否与前中后景的空间关系一致；
- 音频是否对得上口型、动作和环境空间。

### 第五步：可剪辑性

- 第一帧能否接上一镜？
- 最后一帧能否接下一镜？
- 动作是否完整，是否有可用的入点和出点？
- 是否需要倒放、变速、冻结帧或重新构图？
- 后期修补是否能解决，还是必须重生成？
- 本镜是否值得继续重试，还是拆分更便宜？

## 4. 评分

每项 1–5 分：

| 维度 | 1 分 | 3 分 | 5 分 |
|---|---|---|---|
| 提示词遵循 | 主体或动作错误 | 主要信息成立但有偏差 | 关键动作、镜头和结束状态均成立 |
| 身份一致性 | 明显换脸/换装 | 局部漂移但可用 | 多帧稳定一致 |
| 动作与物理 | 变形、穿模、未完成 | 有瑕疵但可剪 | 动作连贯、接触合理 |
| 时间稳定性 | 闪烁、融化、跳帧 | 轻微抖动 | 整段稳定 |
| 构图与摄影 | 主体被裁切、运动错误 | 构图可用 | 构图和运镜准确 |
| 光影与色彩 | 光源矛盾、色板漂移 | 基本统一 | 与 Style Lock 一致 |
| 声音与口型 | 严重错位或缺失 | 可用但有修补 | 同步且空间合理 |
| 连续性与可剪性 | 无法接戏 | 需后期修补 | 可直接接戏 |

关键维度：提示词遵循、身份一致性、动作与物理、时间稳定性、连续性。关键维度原则上不得低于 4/5。

## 5. 问题分级

### P0：硬性失败

- 主体错误或变成另一人；
- 关键动作缺失，故事信息无法成立；
- 严重变形、穿模、融化、肢体异常；
- 画幅或时长明显不符；
- 出现未声明的主要人物/道具；
- 关键道具、文字或方向与上一镜冲突；
- 明显版权、肖像、商标或平台风险；
- 无法安全或合法使用。

P0 不得用“后期也许能修”掩盖。

### P1：需重生成或显著修补

- 动作方向正确但结束状态不清楚；
- 身份轻微漂移；
- 运镜不准确但主体可用；
- 光影突变；
- 背景偶发多余人物；
- 口型或声音明显错位；
- 第一帧/最后一帧无法接戏。

### P2：可接受但应优化

- 轻微构图偏差；
- 少量背景抖动；
- 节奏略慢/略快；
- 色彩偏移但可调；
- 不影响叙事的细节瑕疵。

## 6. 失败原因定位

不要直接把失败都归因于“提示词不够详细”。

| 现象 | 优先排查 |
|---|---|
| 主体变脸/换装 | 参考图职责不清、多人同镜、动作过长、缺少跨镜锚点 |
| 动作未完成 | 单镜事件太多、动作阶段不明确、模型能力限制 |
| 镜头运动错误 | 运镜描述有多重目标、空间不足、参考视频冲突 |
| 背景重建 | 场景参考不足、镜头运动过大、未固定空间锚点 |
| 文字/手机界面错误 | 文字交给生成模型的风险过高，优先后期合成 |
| 手部/道具变形 | 接触动作复杂、遮挡、手部特写过多，拆镜或拍实拍插入 |
| 光线/色彩漂移 | 光影描述矛盾、参考素材色温冲突、模型风格不稳定 |
| 口型不同步 | 对白过长、镜头角度不适合、模型不支持精确同步 |
| 音频不匹配 | 声音描述与画面节奏冲突，后期重建环境声 |

## 7. 反馈与重写

### 反馈格式

必须带时间点和证据：

```text
版本：v003
时间点：00:02.4–00:04.1
问题：右手从小票移到门链时，手指数量和持票位置跳变。
级别：P0
影响：无法与前一镜的手部位置接上。
可能原因：手部动作过细 + 两人同框 + 镜头过近。
修改：拆成“手部插入镜”和“门链特写”两镜；主体动作只保留一个。
```

### 提示词修订格式

每次输出完整的新提示词，不只写“增加一句”。同时列出：

```text
保留：
删除：
新增：
参数变化：
参考素材变化：
预期改善：
可能引入的新风险：
下一版验收标准：
```

### 单变量原则

每轮只改变一个主要变量：

- 提示词结构；
- 参考素材；
- 时长；
- 画幅/构图；
- 模型/版本；
- 拆镜方式；
- 后期替代。

一次同时改五个变量，即使结果变好也无法学习。

## 8. 迭代循环

```text
锁定镜头任务与验收标准
        ↓
生成 v001
        ↓
技术检查 + 关键帧/视频审查
        ↓
定位 P0/P1/P2 问题
        ↓
判断根因
        ↓
选择最小修复：提示词 / 参考 / 参数 / 拆分 / 后期
        ↓
生成 v002
        ↓
与上一版逐项对比
        ↓
通过或继续迭代
```

## 9. 停止条件

停止无意义重试，当出现以下任一情况：

- 连续两轮重试没有改善核心问题；
- 问题来自模型已知限制；
- 需要精确文字、复杂手部或长对白；
- 一个动作拆成两镜更便宜；
- 实拍插入镜比继续生成更稳定；
- 素材权利或平台合规无法解决；
- 用户明确接受当前版本或要求改变风格。

停止时要给出“当前最佳版本”和可执行的替代路径，不要只说“模型不行”。

## 10. 验收结论

```text
结论：通过 / 条件通过 / 不通过
视频版本：
模型与参数：
关键维度评分：
P0 数量：
P1 数量：
可后期修复项：
必须重生成项：
当前最佳版本：
下一轮只改：
预计风险：
```

- **通过**：无 P0，关键维度均 ≥4/5，可直接接戏；
- **条件通过**：无 P0，P1 有明确后期或剪辑修补方案；
- **不通过**：存在 P0，或关键维度 <4/5。

## 11. 版本追踪

每一版至少记录：

- 模型与版本；
- 提示词全文；
- 负向约束；
- 参考素材 ID；
- 时长/画幅/种子/运动强度等参数；
- 生成时间；
- 技术检查；
- 评分；
- 问题与证据；
- 与上一版相比的变化；
- 是否保留及原因。
